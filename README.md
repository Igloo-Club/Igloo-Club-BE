## 📁 Project Structure
```java
└─src
    └─main.java.com.iglooclub.nungil
       ├─config          // Configuration 클래스
       ├─controller      // 컨트롤러 레이어 클래스
       ├─domain          // 엔티티 클래스
       ├─dto             // DTO 클래스
       ├─eventListener   // 이벤트 리스너 클래스
       ├─exception       // 예외 클래스 및 핸들러
       ├─repository      // 리포지토리 레이어 클래스
       ├─service         // 서비스 레이어 클래스
       └─util            // 유틸리티 클래스
```
